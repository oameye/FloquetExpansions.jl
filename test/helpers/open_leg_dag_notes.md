# Open-leg DAG reference

This test-only reference is a graded extension of the sparse Bloch evaluation schedule from PR #144. Internal Floquet mismatch controls model/complement projection and homological inversion. Symbolic external output paths are interned separately and survive model-space projection. Vertex order is explicit, so the one-output `A1` and no-output `A2` vertices contribute at different powers of the amplitude expansion parameter.

This is research scaffolding, not production API.
