Expansion algorithms

After the gauge, the second choice in a Floquet expansion is the algorithm that computes it.

FloquetExpansions.ExpansionAlgorithm — Type
ExpansionAlgorithm

Abstract selector for the algorithm that computes a Floquet expansion within a Gauge.

The gauge fixes which effective generator and micromotion floquet_expansion returns; the algorithm fixes only how they are computed, so algorithms for the same gauge return the same retained coefficients. They do differ in cost. Pass one through the gauge constructor, as in VanVleck(; algorithm=BlochFeshbach()). The implemented algorithms are HoriDeprit and BlochFeshbach.

source

Choosing an algorithm

Keep the default unless a high-order expansion is slow; then time BlochFeshbach on the same generator and order.

FloquetExpansions.HoriDeprit — Type
HoriDeprit <: ExpansionAlgorithm

Select the Hori–Deprit Lie-transform algorithm, which solves for the micromotion generator order by order through nested commutators of the drive harmonics.

HoriDeprit() is the default algorithm of VanVleck, so VanVleck() and VanVleck(; algorithm=HoriDeprit()) select the same gauge. The construction is described in High-frequency expansion.

See also BlochFeshbach.

source
FloquetExpansions.BlochFeshbach — Type
BlochFeshbach <: ExpansionAlgorithm

Select the Bloch/Feshbach wave-operator algorithm. It solves Bloch's equation for the wave operator order by order and normalizes the result to the van Vleck micromotion and effective generator.

For the same generator and order, the retained effective_component and micromotion coefficients equal those of HoriDeprit. The construction is described in Bloch/Feshbach projection.

Examples

julia> h = FockSpace(:cavity); a = Destroy(h, :a);julia> @variables ω::Real t::Real Δ::Real g::Real;julia> H = harmonics(Δ * (a' * a) + g * cos(ω * t) * (a' * a' + a * a), ω, t);julia> bf = floquet_expansion(H, VanVleck(; algorithm=BlochFeshbach()), 3);julia> hd = floquet_expansion(H, VanVleck(), 3);julia> iszero(simplify(effective_generator(bf) - effective_generator(hd)))true
