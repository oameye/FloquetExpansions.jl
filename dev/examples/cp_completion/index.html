CP-preserving completion

A finite-order Floquet expansion of a periodically driven Lindblad generator can leave the completely-positive cone. This tutorial uses Julia's own output to make that phenomenon and its completion visible. The prose introduces the physical models; the matrices, channels, and factorization data below are all returned by FloquetExpansions.

The examples follow the driven-qubit and rank-deficient Gram constructions described in (Ikeda et al., 2021; Schnell et al., 2021). They also compare the algebraic Gram completion with the spectral/HCM completion of Haddadfarshi, Cui, and Mintert (Haddadfarshi et al., 2015).

using FloquetExpansions

A driven qubit

We start with a qubit whose Hamiltonian is driven along $x$ and whose microscopic decay is the jump $\sigma_-$. Keeping the symbols unevaluated is useful here: the returned objects show the inverse-frequency dependence that the package derives from the Fourier components.

pauli = PauliSpace(:cp_doc_qubit)σx = Pauli(pauli, :σ, 1)σy = Pauli(pauli, :σ, 2)σz = Pauli(pauli, :σ, 3)σminus = (1 // 2) * (σx - im * σy)σplus = (1 // 2) * (σx + im * σy)@variables ω::Real t::Real E::Real γ::RealH = (1 // 2) * σz + E * cos(ω * t) * σx

\[E ~ \cos\left( t ~ \omega \right) {\sigma}_{{x}} + \frac{1}{2} {\sigma}_{{z}}\]

The microscopic model is passed to floquet_expansion together with its physical jump channel. order = 3 retains the average and the first two inverse-frequency corrections.

vv = floquet_expansion(H, ω, t, VanVleck(), 3; channels=(jump(σminus, γ),))
FloquetExpansion{VanVleck} of order 3

The effective Hamiltonian is available independently of the dissipative representation.

hamiltonian(vv)

\[\left(\frac{1}{2} + \frac{ - \frac{1}{2} ~ E^{2}}{\omega^{2}}\right) {\sigma}_{{z}}\]

Cartesian coordinates: raw versus completed

A DissipativeFrame fixes the operator directions in which the Kossakowski form is displayed. First use the Cartesian Pauli directions and inspect the raw finite-order result.

cartesian = DissipativeFrame(σx, σy, σz)d_raw = kossakowski(vv, cartesian)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 (1//4)*γ                                  …  0
 im*(((1//4)*(E^2)*γ) / (ω^2) - (1//4)*γ)     0
 0                                            ((1//2)*(E^2)*γ) / (ω^2)

Gram() constructs a graded collapse-amplitude factor and uses its finite Gram product as the positive continuation. The completed Kossakowski matrix therefore contains terms beyond the directly retained expansion.

cp_cartesian = positive_completion(vv, Gram(), cartesian)d_cartesian = kossakowski(cp_cartesian)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 (1//4)*γ                            …  0
 im*((0.25(E^2)*γ) / (ω^2) - 0.25γ)     0
 0                                      ((1//2)*(E^2)*γ) / (ω^2)

The difference isolates the higher-order information supplied by the completion.

d_cartesian - d_raw
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 0  0                      0
 0  (0.25(E^4)*γ) / (ω^4)  0
 0  0                      0

The completion exposes the corresponding finite collapse channels. Their existence is the concrete GKLS representation behind the positive matrix above.

channels(cp_cartesian)
2-element Vector{FloquetExpansions.CollapseChannel{SecondQuantizedAlgebra.QAdd}}:
 collapse(sqrt((1//4)*γ) * σx + (((0.0 + 1.0im)*(E^2)*sqrt((1//4)*γ) + (0.0 - 1.0im)*sqrt((1//4)*γ)*(ω^2)) / (ω^2)) * σy)
 collapse((sqrt((1//2)*(E^2)*γ) / ω) * σz)

The factorization accessor gives the graded data used to construct those channels. The onset list and the full diagnostic object show that a dark Cartesian direction opens at higher order.

cartesian_factorization = factorization(cp_cartesian)
GramFactorization with 2 collapse channels
  onsets: [0, 1]
  stages: 2
    GramStage(grade=0, active_rank=1, dark_rank=2)
    GramStage(grade=2, active_rank=1, dark_rank=1)

The factorization onsets are also available directly.

cartesian_factorization.onsets
2-element Vector{Int64}:
 0
 1

Completion changes only information beyond the retained order. These public-API comparisons check every retained Kossakowski component and the micromotion.

[  kossakowski_component(cp_cartesian, n) == kossakowski_component(vv, cartesian, n)  for n in 0:2]
3-element Vector{Bool}:
 1
 1
 1

The micromotion is unchanged as well.

micromotion(cp_cartesian) == micromotion(vv)
true

The finite completed generator can be reconstructed from its displayed Hamiltonian and collapse channels.

liouvillian(hamiltonian(cp_cartesian); channels=channels(cp_cartesian)) ==effective_generator(cp_cartesian)
true

Frame dependence and two completion algorithms

The entries of a Kossakowski matrix depend on the frame. Use the microscopic jump directions as an adapted frame, where the leading dissipative form has an active direction and dark directions.

adapted = DissipativeFrame(σminus, σplus, σz)d_adapted = kossakowski(vv, adapted)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 (-(E^2)*γ) / (ω^2) + γ    ((1//2)*(E^2)*γ) / (ω^2)  0
 ((1//2)*(E^2)*γ) / (ω^2)  0                         0
 0                         0                         ((1//2)*(E^2)*γ) / (ω^2)

Both algorithms start from exactly this same retained target.

gram = positive_completion(vv, Gram(), adapted)spectral = positive_completion(vv, Spectral(), adapted)kossakowski(gram)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 (-(E^2)*γ) / (ω^2) + ((1//4)*(E^4)*γ) / (ω^4) + γ     …  0
 ((1//2)*(E^2)*γ) / (ω^2) + ((-1//4)*(E^4)*γ) / (ω^4)     0
 0                                                        ((1//2)*(E^2)*γ) / (ω^2)

The spectral continuation is another positive finite matrix in the same frame.

kossakowski(spectral)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 ((1//16)*(E^4)*γ - (1//4)*(E^2)*γ*(ω^2) + (1//4)*γ*(ω^4)) / ((1//16)*(E^4) + (1//4)*(ω^4))              …  0
 ((1//32)*(E^6)*γ - (1//8)*(E^4)*γ*(ω^2) + (1//8)*(E^2)*γ*(ω^4)) / ((1//16)*(E^4)*(ω^2) + (1//4)*(ω^6))     0
 0                                                                                                          ((1//2)*(E^2)*γ) / (ω^2)

The finite continuations are allowed to differ beyond the retained order, while their retained components agree with the raw expansion.

kossakowski(gram) == kossakowski(spectral)
false

The Gram continuation agrees with the raw expansion at every retained order.

[  kossakowski_component(gram, n) == kossakowski_component(vv, adapted, n)  for n in 0:2]
3-element Vector{Bool}:
 1
 1
 1

The same coefficient check holds for the spectral continuation.

[  kossakowski_component(spectral, n) == kossakowski_component(vv, adapted, n)  for n in 0:2]
3-element Vector{Bool}:
 1
 1
 1

Modulated one- and two-photon loss

The next example shows how the package discovers a new dissipative direction generated by the Floquet commutator. Two bosonic reservoirs are modulated with a quarter-cycle phase shift.

fock = FockSpace(:cp_doc_bosonic)a = Destroy(fock, :a)number_selective = a' * a^2frame = DissipativeFrame(a, a^2, number_selective)@variables ωb::Real κ1::Real κ2::Real r1::Real r2::Realu = κ1 * r1 / 2v = κ2 * r2 / 2D1 = dissipator(a)D2 = dissipator(a^2)generator = PeriodicGenerator(  Dict(0 => κ1 * D1 + κ2 * D2, 1 => u * D1 + im * v * D2, -1 => u * D1 - im * v * D2), ωb)vv_bosonic = floquet_expansion(generator, VanVleck(), 2)
FloquetExpansion{VanVleck} of order 2

The explicit frame lets us inspect the raw form produced by the modulated reservoirs.

kossakowski(vv_bosonic, frame)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 κ1                         …  ((1//2)*r1*r2*κ1*κ2) / ωb
 0                             0
 ((1//2)*r1*r2*κ1*κ2) / ωb     0

Gram completion adds the higher-order diagonal terms required by the new cross-channel coupling.

cp_bosonic = positive_completion(vv_bosonic, Gram(), frame)kossakowski(cp_bosonic)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 κ1                         …  ((1//2)*r1*r2*κ1*κ2) / ωb
 0                             0
 ((1//2)*r1*r2*κ1*κ2) / ωb     ((1//4)*(r1^2)*(r2^2)*κ1*(κ2^2)) / (ωb^2)

The completed collapse channels show the new operator direction explicitly.

channels(cp_bosonic)
2-element Vector{FloquetExpansions.CollapseChannel{SecondQuantizedAlgebra.QAdd}}:
 collapse(sqrt(κ1) * a + (((1//2)*r1*r2*sqrt(κ1)*κ2) / ωb) * a' * a * a)
 collapse((sqrt(κ2) + ((-1//2)*r1*r2*sqrt(κ2)*κ1) / ωb) * a * a)

The Gram factorization records the same construction in coefficient form.

factorization(cp_bosonic)
GramFactorization with 2 collapse channels
  onsets: [0, 0]
  stages: 1
    GramStage(grade=0, active_rank=2, dark_rank=1)

Again, the public accessors verify that the finite channels reconstruct the completed generator.

liouvillian(hamiltonian(cp_bosonic); channels=channels(cp_bosonic)) ==effective_generator(cp_bosonic)
true

A rate-modulated qubit

Dissipative Fourier harmonics can mix with coherent harmonics in the same recursion. To expose that mechanism directly, modulate the decay rate of a second qubit with a sine phase. The opposite imaginary coefficients below are the two nonzero Fourier components of that modulation.

mod_pauli = PauliSpace(:cp_doc_modulated_qubit)mod_x = Pauli(mod_pauli, :σ, 1)mod_y = Pauli(mod_pauli, :σ, 2)mod_z = Pauli(mod_pauli, :σ, 3)mod_minus = (1 // 2) * (mod_x - im * mod_y)mod_frame = DissipativeFrame(mod_x, mod_y, mod_z)@variables ωm::Real tm::Real Δm::Real Em::Real γm::Real am::Realmod_dissipator = dissipator(mod_minus)mod_h0 = hamiltonian_action((Δm / 2) * mod_z)mod_h1 = hamiltonian_action((Em / 2) * mod_x)mod_rate_harmonic = (γm * am / 2) * mod_dissipatormod_generator = PeriodicGenerator(  Dict(    0 => mod_h0 + γm * mod_dissipator,    1 => mod_h1 - im * mod_rate_harmonic,    -1 => mod_h1 + im * mod_rate_harmonic,  ),  ωm,)mod_vv = floquet_expansion(mod_generator, VanVleck(), 3)
FloquetExpansion{VanVleck} of order 3

The first two displayed components show the dissipative targets generated at successive inverse-frequency orders.

kossakowski_component(mod_vv, mod_frame, 1)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 0                           …  ((1//4)*Em*am*im*γm) / ωm
 0                              ((1//4)*Em*am*γm) / ωm
 ((-1//4)*Em*am*im*γm) / ωm     0

The next component shows the order-two dark-sector diffusion.

kossakowski_component(mod_vv, mod_frame, 2)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 0                               …  0
 ((1//4)*(Em^2)*im*γm) / (ωm^2)     0
 0                                  ((1//2)*(Em^2)*γm) / (ωm^2)

The Gram completion succeeds on the symbolic positivity stratum and makes the resulting finite channels explicit.

mod_cp = positive_completion(mod_vv, Gram(), mod_frame)kossakowski(mod_cp)
3×3 Matrix{SecondQuantizedAlgebra.Coeff}:
 (1//4)*γm                               …  (0.25Em*am*im*γm) / ωm
 im*((0.25(Em^2)*γm) / (ωm^2) - 0.25γm)     (0.25Em*am*γm) / ωm + (-0.25(Em^3)*am*γm) / (ωm^3)
 (-0.25Em*am*im*γm) / ωm                    ((1//2)*(Em^2)*γm) / (ωm^2)

The completed collapse channels make the positive continuation constructive rather than merely a symbolic claim about a matrix.

channels(mod_cp)
2-element Vector{FloquetExpansions.CollapseChannel{SecondQuantizedAlgebra.QAdd}}:
 collapse(sqrt((1//4)*γm) * σx + (((0.0 + 1.0im)*(Em^2)*sqrt((1//4)*γm) + (0.0 - 1.0im)*sqrt((1//4)*γm)*(ωm^2)) / (ωm^2)) * σy + (((0.0 - 1.0im)*Em*am*sqrt((1//4)*γm)) / ωm) * σz)
 collapse((sqrt((1//2)*(Em^2)*γm - (1//4)*(Em^2)*(am^2)*γm) / ωm) * σz)

The factorization object records the active and dark onset data.

factorization(mod_cp)
GramFactorization with 2 collapse channels
  onsets: [0, 1]
  stages: 2
    GramStage(grade=0, active_rank=1, dark_rank=2)
    GramStage(grade=2, active_rank=1, dark_rank=1)

The conditions are returned as Julia values, so a caller can inspect the physical assumptions and the regularity assumptions used by the symbolic factorization.

positivity_conditions(mod_cp)
2-element Vector{SecondQuantizedAlgebra.Coeff}:
 (1//4)*γm
 (1//2)*(Em^2)*γm - (1//4)*(Em^2)*(am^2)*γm

Regularity conditions describe the symbolic stratum used by the factorization.

regularity_conditions(mod_cp)
4-element Vector{SecondQuantizedAlgebra.Coeff}:
 (1//4)*γm
 sqrt((1//4)*γm)
 (1//2)*(Em^2)*γm - (1//4)*(Em^2)*(am^2)*γm
 sqrt((1//2)*(Em^2)*γm - (1//4)*(Em^2)*(am^2)*γm)

As before, the retained coefficients and finite-generator reconstruction are directly testable through the public API.

[  kossakowski_component(mod_cp, n) == kossakowski_component(mod_vv, mod_frame, n)  for n in 0:2]
3-element Vector{Bool}:
 1
 1
 1

The finite channels reconstruct the completed effective generator.

liouvillian(hamiltonian(mod_cp); channels=channels(mod_cp)) ==effective_generator(mod_cp)
true

The package therefore exposes the full workflow as inspectable Julia values: symbolic effective generators, frame-dependent Kossakowski coordinates, positive finite completions, collapse channels, factorization diagnostics, and the assumptions needed by symbolic elimination.
